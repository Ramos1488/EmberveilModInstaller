# Как добавить мод

1. Сделайте Fork репозитория.
2. Добавьте файл `mods/имя-мода.js` (имя: латиница, цифры, дефис).
3. В начале файла укажите шапку:
```js
   // @name Название мода
   // @author ВашНик
   // @version 1.0
   // @description Короткое описание (до 300 символов)
```
4. Откройте Pull Request. Запись в `catalog.json` добавлять не нужно: она создаётся автоматически после принятия PR.

## API мода

Код выполняется как тело функции с параметрами `EWMod` и `G`:

- `G`: объект игры (`G.game`, `G.Combat`, `G.UI`, ...).
- `EWMod.toast(текст)`, `EWMod.log(...)`.
- `EWMod.store.get(ключ, по_умолчанию)` / `EWMod.store.set(ключ, значение)`: личное хранилище мода.
- `EWMod.online()`: `true`, если игрок в онлайн-режиме.

## Правила

**Запрещено:**
- читать `localStorage`/`sessionStorage`/cookie вне `EWMod.store`;
- отправлять данные на сторонние сайты (`fetch`, `XMLHttpRequest`, `WebSocket`, `sendBeacon`, `<img src>` и т. п.);
- обфусцированный и минифицированный код, `eval`, `new Function`;
- подгружать внешние скрипты;
- менять или читать данные других игроков.

**Онлайн-режим:** если мод даёт преимущество над другими игроками (урон, скорость, золото и т. д.), он обязан проверять `EWMod.online()` и отключать эти функции.

**Размер:** до 200 КБ, один файл.

## Ревью

Мейнтейнер читает код целиком и вправе отклонить любой мод без объяснения причин. После изменения мода хеш пересчитывается автоматически, а обновление проходит через новый PR.
