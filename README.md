# Emberveil Mod Installer

Неофициальный фан-проект: каталог модов и установщик для браузерной игры «Эмбервейл».

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте ссылку и подтвердите установку:
   https://raw.githubusercontent.com/Ramos1488/EmberveilModInstaller/main/installer/mod-installer.user.js
3. Откройте игру и нажмите **F8** (или кнопку «🧩 Моды» в углу).

## Использование

- **Каталог**: моды, одобренные мейнтейнером. Кнопка «Установить» или «Обновить».
- **Установка**: по raw-ссылке, из файла или из кода `EWM1:...`.
- **Установлено**: включить, выключить, посмотреть код, удалить.
- **Поделиться**: подготовить мод к публикации (код EWM1 или запись для каталога).

## Безопасность

- Мод это чужой JavaScript. Он получает **полный доступ** к игре и `localStorage` страницы (сохранения, токены).
- Читайте код перед установкой (кнопка «Код»).
- Моды из каталога проверяются хешем SHA-256 и ревью Pull Request, но гарантий это не даёт.
- **Безопасный режим**: добавьте `#nomods` к адресу игры, и моды не запустятся.

## Структура

```

mods/                           файлы модов

.github/workflows/catalog.yml   автосборка каталога
```
